Sizzle Rush is a fast 2D canvas cooking game: run a tiny kitchen through the dinner rush. Orders arrive on the board with a recipe and a countdown — grab ingredients from the crates, chop tomatoes and lettuce on the board, grill patties on the two-burner stove (leave one too long and it burns), build the exact dish on the plating counter, and serve it at the hatch before the timer runs out. Seven recipes, fast consecutive serves build a combo multiplier, and the rush gets busier as the shift goes on. Reach 600 points before the 3-minute shift ends; 3 late orders ends it early. Original art drawn in code, synthesized WebAudio sounds, no network requests, no build step. Play-tested end to end in a real browser (keyboard + mouse + full shift).

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Or serve `game/` with any static server, e.g. `npx serve game`.
